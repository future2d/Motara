# Motara

[English](README.md) | [简体中文](README.zh-CN.md)

Motara 是一个面向面部捕捉数据处理与虚拟形象控制的跨平台项目。

## PurismCore 合规核验记录

本项目已对 PurismCore 的使用完成内部合规核验。归一化代码片段比对覆盖 Purism 的
52 个源文件或头文件，以及 Live2D 公开 Framework 仓库的 186 个源文件或头文件；
记录的比对结果未发现归一化后连续 12 行及以上完全一致的片段。

该记录仅为有限的技术事实，不构成法律结论。尤其是，它本身不能决定接触、非文字或
实质性相似、合理使用或其他抗辩、以及责任归属等问题。详见
[中文合规记录](docs/legal/PurismCore-Compliance.zh-CN.md)和
[英文版本](docs/legal/PurismCore-Compliance.md)。仓库还在
[`docs/legal`](docs/legal/) 中保留了最高人民法院指导性案例 48 号的来源链接中文记录
及非官方英文译文。

## 项目状态

Motara 仍处于早期开发阶段。此公开仓库目前仅提供项目标识、许可证和商标政策；应用源码、
测试、内部技术文档、构建资源与开发工具暂不在此公开。

## 计划方向

Motara 计划支持面部捕捉输入、可配置的信号处理，以及面向虚拟形象工作流的输出集成。
