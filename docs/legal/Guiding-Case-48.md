## Ruling Abstract

Article 24(1)(3) of the Regulation on Computer Software Protection provides
that deliberately circumventing or destroying technical measures adopted by a
copyright owner to protect software copyright is an infringement of software
copyright. The rule restricts malicious circumvention and protects computer
software copyright. A copyright owner may lawfully adopt technical measures to
protect that copyright, and a person who deliberately circumvents or destroys
such measures bears the corresponding legal responsibility.

The rule must not, however, be misused. It is directed at malicious
circumvention of measures protecting protected software copyright. A copyright
owner's use of a particular format and encryption for output data files, to
prevent machines of other brands from reading those files and thereby preserve
the competitive advantage of machines bundled with the owner's software, is
not a technical measure adopted to protect software copyright within the
meaning of that rule. A claim that software developed by another party to read
that particular file format infringes software copyright is not supported.

## Parties and Background

The plaintiff, Beijing Jingdiao Technology Co., Ltd. ("Jingdiao"), developed a
CNC engraving system consisting of JDPaint CAD/CAM software, a numerical
control system, and machinery. JDPaint generated data files in the Eng format;
control software on a separate computer read those files and converted them
into machining instructions.

The defendant, Shanghai Naikai Electronic Technology Co., Ltd. ("Naikai"),
developed the Ncstudio control software. Jingdiao alleged that Ncstudio could
read Eng files generated by JDPaint even though Jingdiao had encrypted the
format. Jingdiao argued that Naikai had unlawfully circumvented a technical
measure and sought cessation, an apology, and damages. Naikai responded that
Eng files and their format were not objects protected by computer software
copyright and that the two software products differed in their interface,
functions, and application environment.

The courts found that JDPaint output Eng files as data files and that Ncstudio
could read them; in other words, the two products were compatible as to the
output files. The material disputes were whether an encrypted Eng-format data
file was within the protected scope of JDPaint's software copyright and whether
developing software compatible with that format infringed that copyright.

## First-Instance Reasons and Disposition

The Shanghai No. 1 Intermediate People's Court explained that the Regulation
protects computer programs and related documentation. A program is a sequence
of coded or symbolized instructions capable of execution, while documentation
describes a program's content, design, functions, development, testing, or
use. Jingdiao's registrations protected the source code, object code, and
related documentation of JDPaint.

The court held that an Eng-format file was data produced after JDPaint's object
code had been executed. It was not itself an executable instruction sequence.
Its contents were generated from engraving information input by a software
user, rather than being data inherent in JDPaint. The data and format in that
file therefore were not part of the JDPaint program and were not within the
protected scope of JDPaint's computer software copyright. On 20 September
2006, the court dismissed Jingdiao's claims.

## Appeal and Second-Instance Reasons

Jingdiao appealed. It contended that the custom and encrypted Eng format was a
data-exchange format within its CNC system, that the encryption was intended to
prevent use of JDPaint with ordinary control systems, and that reading the
format both circumvented a technical measure and infringed a right of
publication. Naikai requested affirmance.

The Shanghai High People's Court affirmed the factual findings. It reasoned
that the statutory restriction addresses malicious circumvention of technical
measures adopted to protect software copyright. The Eng format performed a
data-exchange function between programs. A different format could have served
the same function. Decrypting the output file would not itself directly cause
an unlawful copy of JDPaint, and the encryption was applied to a file output by
the running software rather than directly to JDPaint itself.

The court further reasoned that Jingdiao's use of the Eng format was intended
to limit use of JDPaint to Jingdiao's CNC system and machinery. Extending
software-copyright protection to bundled products would exceed the scope of
copyright protection for computer software. The restriction on malicious
circumvention protects software copyright; it cannot be used as a tool to
monopolize a market or harm the public interest.

Because the Eng file was not computer software under the Regulation, Jingdiao
had no software-publication right in that file. Developing software capable of
reading JDPaint's Eng files therefore did not infringe that asserted right. On
13 December 2006, the Shanghai High People's Court dismissed the appeal and
upheld the first-instance judgment. The judgment was final.
