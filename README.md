# Motara

[English](README.md) | [简体中文](README.zh-CN.md)

Motara is a cross-platform project for facial-tracking data processing and
virtual avatar control.

## Project Status

Motara is in early development. This public repository currently provides the
project identity, licensing, and trademark policy only. Application source
code, tests, internal technical documentation, build assets, and development
tools are not published here.

## Intended Direction

Motara is planned to support facial-tracking input, configurable signal
processing, and output integrations for virtual avatar workflows.

## Related Repositories

- [Motara.PluginSdk](https://github.com/MotaraSoft/Motara.PluginSdk): future
  public extension contracts and plugin development tools.
- [motarasoft.github.io](https://github.com/MotaraSoft/motarasoft.github.io):
  source for the Motara website.
